# 🧪 The Lab

Welcome to **The Lab**! This repository is my personal sandbox and testing ground. It's a collection of assorted code experiments, web scraping scripts, automation tools, and simple mini-projects that don't need their own standalone repositories.

## 📂 Folder Structure

Because this is a multi-purpose repository, everything is divided into categorized folders to keep the chaos organized:

- **`/web-scraping`** - Scripts for extracting and parsing data from various websites.
- **`/mini-projects`** - Simple, self-contained development projects and web apps.
- **`/scripts`** - Single-file automations, bash scripts, and handy command-line utilities.
- **`/scratchpad`** - Half-baked ideas, API tests, and quick proof-of-concept code.
